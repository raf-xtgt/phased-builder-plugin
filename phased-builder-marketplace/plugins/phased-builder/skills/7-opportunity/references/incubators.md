# Incubators and Accelerators: Agent Reference

Also use this for grants, startup competitions, and founder programs. Read `research-rules.md` first.

## 1. Find candidates
Ask what the user wants: funding, mentorship, network, credits, a program for their region or sector,
remote vs in person. Then search for programs that are **open now** or open soon. Include regional and
remote programs, not only the best-known global ones. For each candidate, open the official page.

## 2. Record for each program (cite each)
- Stage (idea, prototype, revenue), sector focus.
- Location: remote, in person, hybrid; relocation or travel needed.
- **Eligibility blockers:** founder country/citizenship, company registration requirements (and where),
  team requirements (solo founders allowed?), full-time commitment.
- **Deal terms:** money offered, equity taken and on what instrument, fees, other obligations. Plain words,
  plus "not legal or investment advice; read the terms."
- Perks: cloud or tool credits, mentorship, demo day, investor access.
- Application: deadline or rolling, questions asked, video required, what traction they expect.
- Past cohorts: companies from similar stage/region (evidence it's realistic).

## 3. Compare
A short table: program · fit · blockers · terms · deadline · effort to apply. Recommend an order to apply
in, with reasons. The user chooses.

## 4. Gaps
What the program expects that the project doesn't have yet (a demo, users, metrics, a company, a co-founder).
Product gaps become roadmap phases (`2-scope`). Non-product gaps (registration, co-founder) are listed as
tasks for the user, with honest notes on cost and time.

## 5. Application drafts
Interview the user per question. Draft answers in `opportunities/<name>/drafts/application.md`
using their words and real facts from `BUILD_LOG.md` and `PRODUCT.md`. Common questions: one-line
description, problem, why now, what's built, traction, market, competition, team, why this program.
Never invent numbers. Mark gaps in the draft as `[needs: ...]`. The user edits and submits.
